En la aplicación

  • El correo y la contraseña se guardan cifrados mediante la protección de Windows para tu usuario, incluida su copia de recuperación. Cerrar sesión borra ambas copias del acceso.
  • El token de sesión, las lecturas y la gráfica permanecen en memoria durante la sesión.
  • El reloj con Windhawk utiliza un archivo local con valor, tendencia y hora. No contiene cuenta, contraseña, nombre ni identificador de persona. Se elimina al salir o desactivar la integración.
  • Las preferencias se guardan en un archivo local con copia de recuperación.

Conexiones

GlucoTick contacta con el servicio LibreLinkUp de Abbott para autenticar la cuenta y consultar las lecturas compartidas de FreeStyle Libre a las que tienes acceso. Utiliza la cuenta receptora de LibreLinkUp; esta web nunca solicita tus credenciales. Cómo llegan las lecturas a GlucoTick. Contacta con GitHub para buscar y descargar publicaciones de GlucoTick y las dependencias de Windhawk validadas.

No incluye telemetría propia ni envío automático de diagnósticos. Los proveedores externos gestionan estas conexiones según sus propias políticas.

Diagnósticos y desinstalación

El informe técnico copiable no incluye cuenta, lecturas ni preferencias. Los registros detallados de instalación quedan en tu equipo y pueden contener rutas con tu nombre de usuario: revísalos antes de compartirlos.

Al desinstalar puedes conservar o borrar los datos locales. Si eliges borrarlos, también se eliminan las copias de cuenta cifradas y los archivos de recuperación dañados.

En esta web: estadísticas opcionales

La web se aloja en GitHub Pages. Si aceptas las estadísticas, envía visitas y clics de descarga a nuestro servicio de estadísticas alojado en ChatGPT Sites. Registra fecha y hora UTC, página sin parámetros, dominio de procedencia sin ruta, etiquetas de campaña UTM, idioma, familia de navegador, sistema operativo, tipo de dispositivo, país aproximado si el alojamiento lo facilita, versión y formato enlazados y ubicación del botón.

No enviamos datos de glucosa, cuenta LibreLinkUp, credenciales, nombres ni correo. No guardamos IP ni el agente de navegador completo. El alojamiento procesa los datos técnicos necesarios para recibir la conexión; el país puede ser desconocido o inexacto. Los valores de campaña se limitan a etiquetas: no incluyas datos personales en los enlaces.

Solo se mide después de pulsar Aceptar. La decisión se guarda en localStorage con una clave independiente de la versión; una sesión aleatoria en sessionStorage permite estimar sesiones con consentimiento, no personas. No usamos cookies de analítica ni seguimiento entre webs. Se respeta Do Not Track y Global Privacy Control. Puedes cambiar tu decisión con «Preferencias de estadísticas»; rechazar detiene los envíos posteriores y elimina el identificador de sesión de este navegador, pero no borra los eventos ya guardados.

Los registros y consultas de contadores de GitHub se conservan en una base de datos independiente de las versiones para mantener el histórico, sin borrado automático por actualización. El panel y las exportaciones están restringidos al propietario. Los clics no demuestran una descarga completada o instalación; las descargas directas y las actualizaciones de la aplicación actual solo aparecen en el contador acumulado de GitHub, sin procedencia individual.

Rechazar estadísticas no afecta a las descargas ni a la aplicación. La web consulta la API pública de GitHub para mostrar la última versión. GitHub procesa sus conexiones según su política de privacidad.

Las capturas muestran exclusivamente datos ficticios. No conectes tu cuenta ni compartas información de salud en esta web o en incidencias públicas.
