GLUCOSA JUNTO AL RELOJ

Tu glucosa en la
barra de tareas.

Elige una vista discreta, una lectura grande o la integración dentro del reloj. Puedes combinarlas.

GlucoTick es una aplicación de escritorio para Windows, no un widget nativo del panel Widgets. Recibe las lecturas compartidas mediante LibreLinkUp. Prepara la cuenta y conecta.

1. Glucosa en la bandeja

Abre Ajustes → Visualización y elige mostrar la glucosa en el icono. Si prefieres el logo, también puedes dejarlo y usar otra vista para la lectura. Haz clic para abrir el panel o clic derecho para el menú.

2. Un número grande sobre la barra

En Visualización activa el número grande. Ajusta tamaño, ancho, posición y monitor para que no tape elementos que usas. Su fondo es transparente y muestra flecha, unidad y antigüedad. Funciona sin Windhawk.

3. Glucosa dentro del reloj de Windows 11

Abre Ajustes → Visualización → Configurar el reloj de Windows. El asistente prepara la integración opcional con Windhawk para Windows 11 x64. Puede requerir hasta 313 MiB de descarga, 4 GB libres y permiso de administrador.

El asistente permite configurar, reparar o desactivar la integración. Si Windhawk tiene los mods pausados, reanúdalos en Windhawk. Las versiones no validadas se conservan y no se rebajan automáticamente. Ayuda con el reloj.

4. Abre el panel cuando necesites más

El panel muestra valor, tendencia, hora de medición, antigüedad y gráfica de las lecturas recibidas durante las últimas tres horas de la sesión. No descarga un historial completo del sensor.

¿Por qué aparece la lectura en gris?

Después de más de cinco minutos desde la medición, la última glucosa se muestra en gris en todas las vistas. Consultar el mismo dato no lo convierte en reciente. Comprueba la conexión y la antigüedad.

Visor complementario independiente

GlucoTick no es una aplicación oficial de Abbott. No calcula dosis ni sustituye a FreeStyle Libre, sus alarmas o las indicaciones sanitarias. Las lecturas compartidas pueden llegar con retraso. Consulta tu dispositivo o app principal para las decisiones de tratamiento.
