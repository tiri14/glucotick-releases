PRIVACY

Your information,
clearly explained.

In the application

  • Your email and password are encrypted using Windows protection for your user, including their recovery copy. Signing out removes both credential copies.
  • The session token, glucose readings and graph stay in memory during the session.
  • The Windhawk clock bridge uses a local file with reading, trend and time. It contains no account, password, name or person identifier. The file is removed on exit or when integration is disabled.
  • Preferences are saved locally with a recovery copy.

Connections

GlucoTick contacts Abbott's LibreLinkUp service to authenticate and retrieve shared FreeStyle Libre readings you are authorized to see. It uses the receiving account. This website never asks for your credentials. It contacts GitHub for GlucoTick releases and validated Windhawk dependencies.

There is no own telemetry or automatic diagnostic upload. External providers handle connections according to their own policies.

Diagnostics and uninstalling

The copyable technical diagnostic does not include the account, readings or preferences. Detailed installation logs stay on your PC and may contain paths with your Windows username; review them before sharing.

Uninstalling lets you keep or delete local data. Choosing deletion also removes encrypted credential copies and damaged recovery files.

On this website: optional statistics

This website is hosted on GitHub Pages. If you accept statistics, page views and download clicks are sent to our statistics service hosted on ChatGPT Sites. We store UTC time, page path without query parameters, referral domain without its path, UTM campaign labels, language, browser family, operating system, device type, approximate country when provided by hosting, linked release and format, and button position.

We do not send glucose readings, LibreLinkUp accounts, credentials, names or email. We do not store IP addresses or the full user agent. Hosting processes technical connection data; country may be unavailable or inaccurate. Campaign labels are bounded: do not include personal data in campaign links.

Collection starts only after Accept. The preference uses a version-independent localStorage key; a random sessionStorage identifier estimates consented sessions, not people. No analytics cookies or cross-site tracking are used. Do Not Track and Global Privacy Control are respected. Use Statistics preferences to change your decision. Reject stops future events and removes this browser session identifier; it does not delete previously stored events.

Events and GitHub counter snapshots are stored separately from deployed releases to preserve history across website and application updates, without automatic deletion on upgrade. Only the owner can access reports and exports. A click does not prove a completed download or installation. Direct GitHub downloads and updates from the current Windows application contribute only to GitHub totals, without individual attribution.

Rejecting statistics does not affect downloads or the app. The website queries GitHub to display the latest release. GitHub processes connections under its privacy statement.

Screenshots contain fictional data only. Do not share credentials or personal health information on this website or in public issues.

Independent companion viewer

GlucoTick is not an official Abbott app. It does not calculate insulin doses or replace your primary FreeStyle Libre device, app, alarms or clinical advice. Shared readings may arrive late. Use your primary system for treatment decisions.
